# UX Blueprint

## Brand
Primary colors: blue and white. Use dark navy text and light-blue surfaces. Professional, trustworthy, clean and readable on low/mid-range Android devices.

## Authentication
Splash → Sign in/OTP → Verification → Organization resolution → Authorized workspace(s) → Role-specific dashboard.

## Mobile
Home, Work, Learning, Tasks/Messages, Profile. Navigation adapts to role.

## Web
Dashboard, Staffing, Learning, CRM, Marketing, Reports, Documents, Administration.

## Connectivity
Always expose a concise sync state without blocking normal offline work.
